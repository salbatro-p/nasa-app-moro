# MISSIONFORGE 54 — Space Mission Design Game

The submitted game for the NASA Space Apps Challenge 2026, **Space Mission Design Game** challenge. Team Atlas Tech, Sakarya local event.

This folder holds a frozen, self-contained export of the game (`space-mission-design-game.html`, 1,954,622 bytes, all assets inlined except the runtime media). It is recorded here after verification, before any presentation — per the project's delivery rule. The ASTRA FORGE game in `dist/` is untouched. Runtime media (the five cinematic clips, Vera's voiceovers, the eight story voice lines, and the Voyager plasma audio) loads from base64 text assets in this repo (`cine-01-docking.mp4.b64` … `cine-05-europa.mp4.b64`, `vera-intro-01.mp3.b64`, `vera-moon-01.mp3.b64`, `vera-mars-01.mp3.b64`, `vera-bennu-01.mp3.b64`, `vera-europa-01.mp3.b64`, `story-01.mp3.b64` … `story-08.mp3.b64`, `voyager-plasma.mp3.b64`), fetched from the raw file URLs and decoded to blobs.
